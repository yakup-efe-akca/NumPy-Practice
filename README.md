# NumPy Practice

A collection of NumPy exercises focused on numerical computing and array manipulation in Python.

This repository contains practice exercises completed while learning NumPy as preparation for computer vision and image processing projects.

## Topics Covered

1. **Arrays & Indexing** – Creating arrays and accessing elements.
2. **Slicing** – Selecting elements and subarrays.
3. **Shape & Reshape** – Working with multidimensional arrays.
4. **Mathematical Operations** – Performing calculations on arrays.
5. **Boolean Indexing** – Filtering and modifying elements using conditions.
6. **Broadcasting** – Performing operations between arrays of different shapes.
7. **Statistical Operations** – Mean, standard deviation, and axis-based calculations.
8. **Matrix Operations** – Matrix multiplication, transpose, determinant, and inverse.
9. **Array Manipulation** – Concatenation, splitting, and flattening arrays.
10. **Image Pixel Analysis** – Analyzing and modifying pixel values using NumPy.

## Technologies Used

- Python 3
- NumPy
- Jupyter Notebook

## How to Run

1. Download or clone this repository.
2. Install the required library:

   ```bash
   pip install numpy
   ```

3. Open the `.ipynb` file in Jupyter Notebook.
4. Run the cells in order.
